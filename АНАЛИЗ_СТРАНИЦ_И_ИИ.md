## Где ИИ уже завязан на бэкенде (и отображается на фронте)

### 1. Дашборд (`/`, `dashboard-page-content.tsx`)

- **`getDashboardInsight()`** — «Персонализированный инсайт дня», «Финансовая погода» (severity, status, text). Уже отображается в карточках и блоке «Инсайт дня».
- **`getDashboardIndex()`** — финансовый индекс 0–100, факторы (factors_positive / factors_negative), статус (stable / attention / risk). Отображается в карточке «Финансовый индекс».

### 2. Аналитика (`/analytics`, `analytics-page-content.tsx`)

- **`getAnalyticsAnomalies()`** — аномалии расходов (возможная ИИ-логика на бэке). Есть блок «Аномалии расходов» и статус (anomaly_detected / stable).
- **`getAnalyticsHeatmap()`** — heatmap за 90 дней + `explanation` (может быть текстом от ИИ). Вывод в сайдбаре.

### 3. Cashflow (`/cashflow`, `cashflow-page-content.tsx`)

- Использует `getDashboardForecast()`, `getDashboardAlerts()`, `getDashboardInsight()` — те же ИИ-данные, что и на дашборде (прогноз, алерты, инсайт).

## API для ИИ есть, UI не подключён

### Транзакции — голос и чек

В **`src/shared/api/transactions.ts`** уже есть:

- **`voiceParseTransaction(body: VoiceParseBody)`**  
  - `POST /v1/transactions/voice-parse`  
  - Тело: `{ text: string }`  
  - Ответ: `{ amountMinor, categoryId, memo }`

- **`receiptOcrTransaction(file: File)`**  
  - `POST /v1/transactions/receipt-ocr` (multipart)  
  - Ответ: `{ amountMinor, date, memo, categoryId }`

В **`transactions-page-content.tsx`**:

- Кнопки «Сканировать чек камерой» и «Голос: „1500 на такси“» — **disabled**, подпись «скоро».
- Блок «AI-категоризация» — только текст «Категория подставляется по счёту и истории», без вызова API.

**Модалка добавления транзакции** (`add-transaction-modal.tsx`) — только ручной ввод (сумма → категория → счёт/комментарий), вызовов `voiceParseTransaction` / `receiptOcrTransaction` нет.

## Рекомендации по интеграции ИИ на фронте

1. **Транзакции — голос**
   - В сайдбаре или в модалке добавления: поле ввода/кнопка «Голос» → вызов `voiceParseTransaction({ text })` → подстановка `amountMinor`, `categoryId`, `memo` в форму и переход к шагу 2/3 или сразу сохранение.
   - Включить кнопку «Голос: „1500 на такси“» и привязать к этому потоку.

2. **Транзакции — сканер чека**
   - Кнопка «Сканировать чек» → выбор файла/камера → `receiptOcrTransaction(file)` → подстановка суммы, даты, memo, категории в форму добавления транзакции.
   - Убрать `disabled` после подключения API.

3. **AI-категоризация**
   - Если бэкенд при создании/обновлении транзакции сам подставляет категорию (по счёту/истории), на фронте можно показывать подсказку «Подобрано ИИ» рядом с полем категории при создании/редактировании.

4. **Дашборд и Cashflow**
   - Уже используют insight/index/forecast/alerts. При появлении новых ИИ-полей на бэке (например, рекомендации действий) — добавить блоки в те же компоненты.

5. **Аналитика**
   - Аномалии и heatmap explanation уже отображаются. При расширении ответов ИИ (например, текстовые советы) — вывести их в тех же карточках.

## Навигация (AppShell)

Основные пункты: **Главная**, **Транзакции**, **Аналитика**, **Бюджеты и цели**, **Профиль**.  
Мобильное меню: те же + «Ещё» (подменю с планированием и др.).

Имеет смысл подключать ИИ в первую очередь на **Дашборде** (уже есть), **Транзакциях** (голос + чек) и при необходимости — в **Аналитике** и **Планировании** по мере появления новых эндпоинтов на бэке.
