# Суммы во фронтенде

Во всём приложении суммы в полях `amount_minor`, `*_minor`, `amountMinor` трактуются как **целые единицы валюты** (например, тенге), без умножения на 100.

- Формы: пользователь вводит целые суммы (1500 ₸), в API уходит то же целое число.
- `formatMoney()`: по умолчанию **не** делит на 100. Если когда-то понадобятся настоящие тиыны — передайте `{ divideBy100: true }`.

Это согласовано с текущим бэкендом FinTrack (поля исторически названы `*_minor`).

Ответы **voice-parse** и **receipt-ocr** в поле `amountMinor` должны использовать те же **целые ₸**, что и `POST /transactions`, иначе на шаге «Сумма» отображение будет неверным.
